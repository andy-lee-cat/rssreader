## 使用flask框架重构langgraph api

langgraph这边我希望整体都在ai路径下，然后启动一个服务用于langgraph服务。通过api和rssreader服务进行交互。

在ai/src/agent/summary路径下我定义好了一个ai服务summary.py，里面的变量workflow是最终的构建好的langgraph图。我现在不想用langgraph自带的闭源langsmith。

我想用flask框架来写api。初步设计是rssreader那边不做用户的大模型信息存储，langgraph这边做存储（api key，model等）。所以我理解应该需要传入userid，isstreaming，被总结的文本。

设计流式输出与非流式输出的逻辑。

  1. 摘要生成

  POST /api/summary/generate

  {
      "user_id": 1,
      "content": "需要总结的文本...",
      "streaming": true/false
  }

  非流式响应:
  {"success": true, "summary": "摘要内容..."}

  流式响应 (SSE):
  data: {"chunk": "文"}
  data: {"chunk": "字"}

      "model_name": "qwen-max",

  GET /api/config/model?user_id=1

## 修改为数据库存储

现在文件存储还是太不好了。还是修改成用数据库存储的。现在的rssreader主项目是用的本地的pgsql，你可以看看他的实现，然后决定是用同一个数据库还是用不同的数据库。

### reply

```markdown
● 已完成 PostgreSQL 存储改造。最终结构：

  ai/
  ├── .env.example           # 环境变量示例（含 DATABASE_URL）
  ├── requirements.txt       # 新增 psycopg2-binary
  ├── run.sh
  └── src/
      ├── agent/summary/     # LangGraph 工作流
      ├── api/               # Flask API
      ├── config/
      │   └── user_model.py  # 用户配置（PostgreSQL 实现）
      └── database/
          ├── __init__.py
          └── connection.py  # 数据库连接池 + 表初始化

  关键改动

  1. 数据库表结构

  CREATE TABLE user_ai_configs (
      id SERIAL PRIMARY KEY,
      user_id INTEGER NOT NULL UNIQUE,
      provider VARCHAR(50) NOT NULL,      -- tongyi, openai, deepseek
      api_key VARCHAR(500) NOT NULL,
      model_name VARCHAR(100) NOT NULL,
      temperature REAL DEFAULT 0.3,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
      updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
  );

  2. 数据库连接

  - 使用与 rssreader 相同的 DATABASE_URL 环境变量
  - 默认连接: user=postgres password=postgres dbname=miniflux2
  sslmode=disable
  - 使用连接池（psycopg2.pool.ThreadedConnectionPool）

  3. 表自动初始化

  Flask 应用启动时自动创建 user_ai_configs 表（如不存在）

  4. 外键约束

  user_id 关联 rssreader 的 users 表，用户删除时配置自动级联删除

  使用方式

  cd ai
  pip install -r requirements.txt

  # 确保 PostgreSQL 运行且 miniflux2 数据库存在
  ./run.sh dev
```
